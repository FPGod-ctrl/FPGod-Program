# Client Statements — Drop Folder

Drop each client's statement(s) in here, then tell me **"process the client statements"**.

## What to drop
- Super / pension / investment statements (PDF, Word, or scanned images)
- Any file format is fine — I'll read them.

## How to organise (recommended)
One file per client is easiest. If a client has multiple statements, either:
- **Option A:** name them with the same prefix, e.g.
  - `Smith John - Super.pdf`
  - `Smith John - Pension.pdf`
- **Option B:** make a subfolder per client, e.g.
  - `Smith John/` → drop all their statements inside

Naming files `Surname Firstname` helps me match and label each email correctly.

## What I'll produce
For each client, a personalised email (former fee-paying / "ceased fee" clients) that:
1. Flags the concern that their super has had **no active management** since fees ceased.
2. Uses their **age + account details** to identify concrete opportunities we can add value on
   (drawn from the plan-generator strategy ideas — e.g. contribution strategy, investment
   option/risk mismatch, insurance inside super, fee drag, consolidation, pension/TTR, beneficiary nominations).
3. Explains why a **review meeting** matters and what value it unlocks.
4. Keeps a warm, compliant tone (no specific product recommendations without a full SOA — general "worth reviewing" framing only).

Draft emails land in: `generated-plans/client-emails/`

These are **drafts for your review**. I'll flag anything that would need a full SOA
