# Insurer and super fund logos

For the portfolio table in SOAs: the logo goes above the product name in the Description cell
of the **Proposed** row(s) only.

## `xplan/` — use these by default

XPLAN / Risk Researcher's own transparent PNGs (60 × 34 px, Acenda 60 × 22). These are byte-for-byte
the images the firm's XPLAN-generated SOAs embed, so they match house SOAs exactly. Insert at
about **1.6 × 0.9 cm**.

Insurers: acenda, aia, amp-life, clearview, encompass, futura, metlife, neos, nobleoak, onepath,
pps-mutual, resolution-life, tal, zurich.

Super funds (`super-` prefix): australiansuper, aware-super, caresuper, cbus, hesta, hostplus,
mercer, perpetual, qsuper, rei-super, rest, super-sa, unisuper.

**Not yet found:** Brighter Super (OnePath's super trustee), CFS, Australian Retirement Trust,
MLC/Insignia, Colonial First State FirstChoice, Netwealth, HUB24. To add one, scan a Risk Researcher PDF
that includes it (premium table logos are 60 px wide) and save it here.

## `hires/` — larger copies, for anything other than the portfolio table

acenda, clearview, metlife, onepath, tal. Taken from insurer quotes and letters in local case
folders.

## Where they came from (26 Oct 2026)

`xplan/`: extracted with their transparency from Risk Researcher PDFs in SharePoint client
folders, read-only (nothing written to SharePoint), plus local case folders. `hires/`: local case
folders. Harvest workings: `../../.logo-harvest/` (can be deleted).
