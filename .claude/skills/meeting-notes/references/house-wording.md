# Initial Meeting Notes: fixed wording

Use these strings exactly. Placeholders in angle brackets.

| Text | When | Where |
|---|---|---|
| `TBC` | A fact that should be known was not said | In the field it belongs to. Highlighted yellow. |
| `NOT KNOWN` | One detail of a listed policy is unknown | Inside the structured cover listing only |
| `EXISTING COVER REMAINS IN FORCE` | Existing cover is confirmed | Last line of `Current Insurance`, always written (default, Q-MN-11) |
| `EXISTING COVER (IF ANY) REMAINS IN FORCE` | Nothing has been confirmed to exist | Last line of `Current Insurance` (default, Q-MN-11) |
| `Estimated net position approx. $X.` | Always, in Financial circumstances | After the liabilities total |
| `Same as <spouse first name>.` | Spouse's position mirrors the client's | Appended in place of the repeated detail |
| `... have been disclosed` | Any absence ("No ... have been disclosed") | Anywhere an absence is recorded |
| `... as a minimum` | Describing the scope of cover sought | Usually `Reasons for seeking advice` |
| `PAYG $000,000 + Super` | Format of `Employer/self` | Header |
| `private school` | School fees are in play | `About the client` |
| `OUTSTANDING - TO BE OBTAINED` | First-contact enquiry with too many gaps for fields | Closing list, only in that case |
| `Both to be explored further however, client has disclosed <partial fact>.` | Pattern for a `TBC` field with a qualifying line | Under the `TBC` |

Wording that must never appear: "Not disclosed" (default, Q-MN-10), "came through unclearly", "figure unclear on the call", "[CONFIRM spelling]", "stated as X and recorded as Y", "spelled verbally and is to be confirmed", "fund not known; to be confirmed", "NOT CAPTURED" appended to a sentence, "are held" for an absence, "No binding death benefit nominations discussed."
